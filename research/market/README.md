# Рынок → навык → доказательство → пробел

Срез от 2026-11-26, выборочная перепроверка 2026-11-27. 36 наблюдений: 33 содержательных текста и 3 частичных. Это целевая разведочная выборка, **не статистика всего рынка** и не доказательство того, что Python популярнее других языков: Python участвовал в поиске.

- `batches/`: первичные наблюдения с URL, датой, доступностью, исходными required/preferred, оплатой, географией и ограничениями.
- `skill-aliases.json`: только точные полные алиасы сохранённых требований; составная альтернатива остаётся альтернативой. Пустой массив не доказывает отсутствие спроса.
- `requirement-matrix.csv`: производное сопоставление 530 требований с навыками, результатами курса и планируемыми проектами. Перегенерация: `uv run --project projects/learning-hub learning-hub --root . market-export`.
- `/market` и `/api/market`: наблюдения и матрица. Статус освоения берётся отдельно из реальных учебных записей.
- `review-notes.md`: происхождение, повторные проверки, возможный клиентский дубль и ограничения извлечения.

Публикация вакансии, проверенный текст, подходящий навык, готовность кандидата и доступность найма — разные свойства. В этом срезе **ни одна** запись не подтверждает одновременно удалённый найм пользователя из РФ/Казахстана и минимум $5000/month net. Годовой gross, B2B, бонусы, equity и unknown не конвертируются в net. Работа из РФ предпочтительна, из Казахстана — дополнительный вариант, но личные условия договора пока не проверены.

## Обновление

При новом срезе сохранять новые batch/дату и историю. Не менять checked_on без повторного чтения источника. Проверять активность в первичном ATS/тексте работодателя; недоступные карточки помечать partial или исключать с причиной. Для каждого нового требования сохранять источник и контекст обязательности, разделять альтернативы, задачи и требования. Не копировать полные тексты вакансий.

Дедупликация ID/URL обязательна. Общий клиент у разных рекламодателей может остаться неизвестным; это ограничение частот. Соседние data, research, advocacy и разовые роли анализировать отдельно. Для приоритизации учитывать повторяемость, доступность конкретного найма, цену пробела и скорость появления убедительного кейса. Новая модная библиотека не переписывает программу автоматически.

Частоты интерфейса считают долю **сохранённых verified публикаций**, где есть точный алиас required skill, с уникальным учётом навыка внутри публикации. Preferred и partial в знаменатель не добавляются. Навыки курса крупнее отдельных технологий: совпадение слова не подтверждает все критерии результата.
