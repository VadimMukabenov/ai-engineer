# AI Engineer · learning & evidence

Личный курс и портфолио для удалённых AI Engineering ролей. Основной стек — Python; работа из РФ предпочтительна, Казахстан — дополнительный вариант. Ориентир: от $5 000 net в месяц, цель $10 000+. Оффер и грейд подтверждаются наймом, прохождение курса их не гарантирует.

## Начать

```bash
make setup
make verify
make test
make serve
```

Открыть [учебный кабинет](http://127.0.0.1:8765). Начать с **D00 — диагностики**: написать собственный ответ и сохранить попытку. Это ещё не зачёт. Codex затем проводит ревью, объясняет пробелы и назначает независимую проверку по опубликованным критериям.

Python 3.12+, uv, Git. Системные пакеты, VPN, ядро и драйверы не меняются. Приложение слушает только loopback; это личный локальный инструмент, не сервис для публичного размещения.

## Local-first LLM

```bash
make llm-smoke
```

Используется официальный OpenAI Python SDK → `http://127.0.0.1:11434/v1` → существующий `qwen2.5-coder:7b` в Ollama. Smoke проверяет интеграцию, не знания ученика. Код упражнения в `labs/direct-llm-api/` оставлен для самостоятельной работы.

Будущий облачный профиль: `AI_PROVIDER=openai`, `AI_ALLOW_CLOUD=1`, согласованный `AI_PAID_BUDGET_USD`, `OPENAI_API_KEY` и явный `LLM_MODEL`. Переключение не означает одинаковую поддержку structured output, tool calling, streaming и reasoning: это проверяется отдельно. До согласования бюджета остаёмся на локальном профиле; платные вызовы не выполнялись. Ключи — только в окружении, никогда в Git. Бюджет в этом профиле — явное разрешение, а не точный счётчик расходов: перед платными экспериментами нужен лимит у провайдера и учёт стоимости.

## Проверки и изменения

`make verify` проверяет ссылки, предпосылки, обязательные модули/проекты, версии критериев и hashes доказательств/утверждённого контракта. `make test` проверяет негативные сценарии и сохранение попыток. CI повторяет проверки. Переименование или удаление результата требует миграции истории; новые рыночные данные сами по себе не меняют утверждённую программу.

Это защита от случайного дрейфа и способ увидеть нарушения. Пользователь с правом изменения кода и CI способен переписать проверки; независимая серверная защита веток пока не подтверждена. См. [протокол изменений](governance/README.md).
